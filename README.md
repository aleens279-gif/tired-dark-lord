> Heroes. Always at the door before I've had my tea. Listen — the ritual is ready, the moon is right, the ancient seal is one chant from breaking, and honestly I just want to sit down. So yes, kneel if you must, but make it quick. I've got a kingdom to conquer, a prophecy to fulfill, and a nap that has been rescheduled since the Third Age.
